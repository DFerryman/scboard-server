# Runtime dependencies for the sync-only server.
#
# Pair this with ``server/constraints.txt`` for reproducible installs:
#   .venv/bin/pip install -r server/requirements.txt -c server/constraints.txt
#
# Bounds rationale:
# - pydantic 2.10 is the oldest line we've validated against; lower bound
#   prevents accidental install of 2.0-2.9 (which had behaviour drift around
#   validators and serialization).
# - <3 keeps the major version locked; pydantic 3 will be a breaking change
#   when it lands and must be re-validated.
# - Pillow 12 requires a newer Python than the current service venv's Python
#   3.9, so keep the runtime range on the 10/11 line until Python is upgraded.
pydantic>=2.10,<3
Pillow>=10,<12
